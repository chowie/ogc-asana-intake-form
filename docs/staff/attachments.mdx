You can attach one supporting document — a quote, a photo, a floor plan, a
spreadsheet. It's uploaded to the Asana task after the task is created.

## Accepted files

| Type | Extensions |
|---|---|
| PDF | `.pdf` |
| Word | `.doc`, `.docx` |
| Excel | `.xls`, `.xlsx` |
| Images | `.png`, `.jpg`, `.jpeg` |

**Size limit: 700 KB.** Anything larger is rejected in the form before you
submit, with the message *"File must be 700 KB or smaller."*

<Tip>
  Phone photos are usually 2–5 MB. Email the photo to yourself and choose
  "Medium" or "Small" size, or use your phone's built-in resize option before
  attaching.
</Tip>

## Only one file

The form takes one attachment. If you have several, either:

- Combine them into a single PDF, or
- Submit the request, then add the rest directly to the Asana task from the link
  on the confirmation screen.

## When the upload fails

The task is created **first**, then the file is uploaded. So if the upload fails,
your request still went through. The confirmation screen tells you the
attachment didn't make it.

<Warning>
  Do not resubmit the form after an attachment failure — you'll create a
  duplicate request. Instead, open the task from the confirmation link and drag
  the file onto it in Asana.
</Warning>

## Removing a file before submitting

Once selected, the file name shows with an **✕** next to it. Click it to clear
the selection.
