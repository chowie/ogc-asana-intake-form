## Patterns used

**Mocking the roster.** `src/config/staff.js` is replaced with `vi.mock` +
`vi.hoisted` in `IntakeForm.test.jsx`, so the tests don't depend on whatever
happens to be in `data/roster.json`.

```js
const { STAFF } = vi.hoisted(() => ({ STAFF: [/* fixtures */] }))
vi.mock('../config/staff.js', () => ({ STAFF, findStaff: (n) => ... }))
```

**Mocking fetch.** `vi.stubGlobal('fetch', ...)` is used in `App.test.jsx` and
the function tests. In `auth-flow.test.js`, it also captures the outgoing Resend
calls, so tests can pull the token out of the "sent" email
(`tokenFromLastEmail`).

**Fake Redis.** `netlify/functions/__tests__/helpers/fake-redis.js` is a small
in-memory stand-in for the `@upstash/redis` client. It covers only the commands
the auth code uses (`get`, `set` with `ex`, `getex`, `getdel`, `del`). It also
mimics Upstash serialization: strings are stored raw, everything else as JSON,
and every read is `JSON.parse`d with a raw-string fallback. That way, tests
catch values that wouldn't round-trip through the real client. Tests
swap it in with `vi.mock('../_shared/redis.js')`. TTLs read `Date.now()`, so
`vi.setSystemTime` / `vi.advanceTimersByTime` drive expiry. `seedSession()`
creates an active user plus a session and returns the cookie. The
`create-task`, `chat`, and `attach-task` tests use it.

**Google.** `auth-flow.test.js` mocks `verifyGoogleIdToken`, where
`"google:<email>"` stands in for a valid token. `google.test.js` runs the real
`jose` verification against locally generated keys.

**The PII guard.** `data/__tests__/roster-placeholder.test.js` fails the build if
`data/roster.json` looks like real staff data rather than the placeholder. This
exists because real names, emails, and Asana GIDs were committed once already.

<Warning>
  Don't "fix" that test by loosening it after running `npm run refresh-roster`
  locally — the generated roster is not meant to be committed. Revert
  `data/roster.json` before committing.
</Warning>

## What isn't covered

No browser end-to-end tests. The Asana, Anthropic, and Resend APIs are mocked at
the `fetch` boundary, and Redis is the in-memory fake. Nothing in CI hits a live
service. The Google button itself (Google's script) isn't exercised.
